# Atelier Vesper — LARK No. 01

An original, fictional luxury-product concept built as a Scrollcraft-style layered web experience.

Open `index.html` in a modern browser. No build step or external dependency is required.

## Experience architecture

- A pinned overture transforms the automaton from closed sculpture to open mechanism as the visitor scrolls.
- A second pinned chapter moves through the physical cylinder, comb, and governor.
- Editorial intervals explain the human craft, acoustic character, rarity, and commissioning ritual.
- “Hear the movement” creates a short synthesized music-box study through the browser Web Audio API. It never autoplays.
- Reduced-motion, keyboard focus, semantic headings, responsive layouts, and useful image descriptions are included.

All names, claims, contact details, product specifications, and imagery are part of a fictional design exercise.
